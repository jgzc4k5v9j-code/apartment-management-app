# apartment-management-app
# アパート管理支援Webアプリ

Spring BootとReactで開発したアパート管理支援Webアプリです。

## 概要

アパートの管理業務を効率化することを目的としたWebアプリです。
入居者情報の管理と修繕依頼の管理を一つのアプリで行えるようにし、管理人と入居者で利用できる機能を分けています。

## 開発背景・目的

身近な知人がアパート経営をしており、入居者情報の管理や修繕依頼への対応など、日々の管理業務に手間がかかっていることを知ったことが開発のきっかけです。
そこで、入居者情報と修繕依頼を一つのWebアプリでまとめて管理することで、アパート管理にかかる負担を軽減できるのではないかと考え、本アプリを開発しました。
管理人が入居者情報や修繕依頼をまとめて確認・管理できるだけでなく、入居者側からも自分に関する情報や修繕依頼を確認できるよう、利用者ごとに必要な機能を分けています。
実際の利用場面を想定しながら、管理業務をより分かりやすく、効率的に行えることを目指しました。

## 主な機能

### 管理人

- 管理人ログイン
- 入居者一覧表示
- 入居者情報の登録・編集・削除
- 入居者詳細表示
- 入居者ごとの修繕履歴確認
- 修繕依頼一覧表示
- 修繕依頼の詳細表示
- 修繕依頼の登録・編集・削除
- 修繕依頼のカテゴリ管理
- 修繕依頼の対応状況変更
- 修繕依頼の対応状況による絞り込み

### 入居者

- 入居者ログイン
- 自分の入居者情報の確認
- 自分に関する修繕依頼の確認

## 修繕依頼のカテゴリ

修繕依頼は以下のカテゴリから選択できます。

- 水回り
- 電気
- 建具・ドア
- エアコン・空調
- その他

## 修繕依頼の対応状況

対応状況は以下の3種類で管理します。

- 未対応
- 対応中
- 対応済み

## システム構成

```text
[ React / Vite ]
       ↓ REST API
[ Spring Boot ]
       ↓
[ H2 Database ]
```

フロントエンドとバックエンドを分離し、Spring BootでREST APIを構築しています。

## データ構成

主に以下のデータを管理しています。

### Resident（入居者）

- ID
- 氏名
- 部屋番号
- 電話番号

### RepairRequest（修繕依頼）

- ID
- 入居者ID
- カテゴリ
- 内容
- 対応状況

入居者と修繕依頼を関連付けることで、入居者ごとの修繕履歴を確認できるようにしています。

## ローカル環境での起動方法

### 1. バックエンドの起動

`backend` ディレクトリを開き、Spring Bootアプリケーションを起動します。

バックエンドは以下のポートで起動します。

```text
http://localhost:8080
```

### 2. フロントエンドの起動

`frontend` ディレクトリで以下を実行します。

```bash
npm install
npm run dev
```

起動後、表示されたURLからブラウザでアクセスします。

例：

```text
http://localhost:5174
```
